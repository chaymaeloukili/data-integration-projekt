# Raw data

Original data files, saved as they come from the source. Files in this folder are never changed.
Cleaned data goes to `data/processed/`.

| Folder | Source | Licence |
|---|---|---|
| [destatis](destatis/README.md) | Federal Statistical Office of Germany (Destatis): population | dl-de/by-2-0 |
| [ffa](ffa/README.md) | FFA (German Federal Film Board): cinema tickets, visitors, spending | Permission from the FFA |
| [kaggle](kaggle/README.md) | Kaggle: Letterboxd Movie Rating; Top 500 Movies Ranked by IMDb, Rotten & Letterboxd | CC BY 4.0; CC BY-NC-SA 4.0 |

**Note on Kaggle:** The Kaggle files are too large to upload to GitHub. The folder only contains the links to the datasets. To use the data, download it from Kaggle (free account needed) and do not upload it to this repository.

More details on all sources: [docs/sources](../../docs/sources/README.md)
