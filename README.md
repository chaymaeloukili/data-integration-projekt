# Cinema Visits in Germany (2000–2025) 🎬

Group project for the module DIS 3.3 Data Integration (Timo Breuer), TH Köln, winter semester 2026/27.

> **Status:** Work in progress. Research questions and plan will follow by 13.11.2026.

## Topic

We look at how cinema visits in Germany have changed since 2000: the rise of streaming, the COVID-19 closures and the recovery afterwards. We combine data on cinema visits and population by year.
